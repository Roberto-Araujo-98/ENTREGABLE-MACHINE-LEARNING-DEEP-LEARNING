Conectar Tu Modelo Exportado de Python (Keras)

Para cargar la arquitectura de Red Neuronal Convolucional (CNN) entrenada en Python con Keras en esta plataforma web, debes exportar el modelo a formato model.json.

1 Instalar Conversor de TensorFlow.js en Python: 

pip install tensorflowjs

2 Convertir tu archivo h5 / keras guardado: 

tensorflowjs_converter --input_format=keras modelo_mnist.h5 ./tfjs_model
